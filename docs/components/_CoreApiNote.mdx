:::info Redux Toolkit

本页介绍 Redux Toolkit 所基于的 Redux 底层机制。在实际应用中，通常会使用 Redux Toolkit 的 [`configureStore`](/toolkit/api/configureStore) 和 [`createSlice`](/toolkit/api/createSlice)，而不是自行编写这些底层代码。不过，了解这些 API 的底层原理仍然很有价值。

了解如何使用当前推荐的方式编写 Redux 应用，请参阅 [Redux Essentials 教程](../tutorials/essentials/part-1-overview-concepts.md)。如需更新现有代码，请参阅[迁移到现代 Redux](../usage/migrating-to-modern-redux.mdx)。

:::
